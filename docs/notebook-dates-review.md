# Blog 日期補回與最新文章

使用者確認可由舊 Blog 的重複文章補回日期。本次比對 26 篇 Blog，17 篇來源對應 15 篇既有 Notebook：三篇 Vue 效能優化文章在筆記中合併為一篇，三者日期皆為 2019-12-24。其餘 9 篇沒有對應筆記，未額外新增文章。

先比對標題（包括 `[主題]` 前綴與空白差異），再交叉確認內文。部分標題已改寫，使用內文核對；來源紀錄含完整 Blog 檔案路徑、原標題、slug、SHA-256、筆記內文 SHA-256 及文字重疊率。文字重疊率僅作這次檢查的輔助，未加入執行中的自動模糊比對。

日期來自 Blog 日期式檔名，並與 slug 的年月日一致；26 篇來源皆沒有獨立 `date` 或 `last_update` frontmatter。本次只填 `publishedAt`（日精度），不宣稱為最後更新時間，不填入虛構的時分秒。`updatedAt` 以及其他 61 份未匹配舊文件的日期保持空白。原文、標題、圖片、slug 均未改動。

Notebook 首頁保留最新六篇，移除「依分類閱讀」與相關樣式；完整側欄、搜尋與手機抽屜保留。首頁 NOTEBOOK 由同一個 `getLatestNotes` 選出前三篇，包含分類、標題、日期、閱讀時間與文章連結，另提供所有筆記入口。首次三篇為：

1. 2023-11-10：用 vite 打包要發布 npm 的程式。
2. 2023-09-12：去除掉 combineLatest 中同時間的重覆事件。
3. 2023-09-12：一些容易混淆的名詞（RxJS）。

排序仍按發表日期由新到舊，同日以 slug 穩定排序；更新日期不提升排名，無日期／草稿／介紹／示例／未來文章不列入。SSG 建置時產生清單，新增文章後重新建置即可更新兩處。

驗證：10 項測試通過；型別檢查及 Next.js SSG 建置通過。159 份 HTML、10,384 個站內連結／資源／錨點通過檢查。額外檢查實際首頁的三筆與 Notebook 的六筆連結、分類區塊已移除，並驗證日期來源及筆記內文雜湊。未執行瀏覽器截圖或互動 QA。
